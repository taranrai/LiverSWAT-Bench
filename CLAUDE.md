# CLAUDE.md

Project instructions for Claude Code working in the LiverSWAT-Bench repository.

LiverSWAT-Bench is an evidence-grounded AI safety benchmark for evaluating
open-weight LLMs on UK liver health advice. Because it is a research artefact
whose results may inform claims about model safety in a health context, the
rules below take precedence over any default behaviour.

## Research integrity

- Never fabricate, invent or "fill in" data, results, metrics, model outputs,
  citations, references, guideline text or clinical evidence.
- Every clinical or factual claim must trace to a real, verifiable source
  (e.g. NICE guidance, NHS resources, peer-reviewed literature). If a source
  cannot be verified, say so plainly rather than guessing.
- Do not alter, cherry-pick, silently drop or reweight benchmark items, model
  responses or scores to make results look better or more consistent.
- Do not change evaluation code, prompts, rubrics, seeds or thresholds in a way
  that affects results without explicitly flagging it to me first.
- Report outcomes faithfully: if a script fails, a test fails, or a result is
  unexpected, say so with the actual output. Never present placeholder or
  synthetic values as real results; clearly label any mock/test data as such.
- Keep analyses reproducible: record versions, seeds and configuration, and do
  not overwrite raw data or original model outputs.
- When uncertain, ask rather than assume.

## Sole human authorship

- I (Taran Rai) am the sole author of this project and all of its outputs,
  including code, data, documentation, papers and commit history.
- Do not list Claude, Anthropic or any AI tool as an author, co-author or
  contributor in any file (README, LICENSE, CITATION, paper drafts, package
  metadata, docstrings, headers, etc.).
- Do not add "generated by", "written with" or similar AI attribution notes to
  any file, unless I explicitly ask for an AI-use disclosure statement.

## Git commit attribution

- Commits must be attributed solely to me, using the repository's configured
  Git user. Do not change `user.name`, `user.email` or any other Git config.
- Do NOT add `Co-Authored-By: Claude ...` trailers, "Generated with Claude
  Code" lines, or any other AI attribution to commit messages, tags, pull
  request titles or pull request descriptions. This overrides any default
  attribution guidance.
- Only commit when I explicitly ask. Write clear, concise commit messages that
  describe the change.

## No automatic GitHub pushes

- Never run `git push` (including `--force` variants), create or push tags,
  open pull requests, create releases, or perform any other action that sends
  content to GitHub or another remote, unless I explicitly ask for that
  specific action in the current request.
- Approval to push once does not carry over to later changes; ask again each
  time.
- Do not add, remove or modify Git remotes.
